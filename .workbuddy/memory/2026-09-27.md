  计算让位宽度 `reserve = max(0, RAIL - leftGutter)`；视口 < 1024px 退化底部通栏停靠（docked）。
  常量：SIDE_PANEL_WIDTH=320 / GAP=24 / RAIL=368 / DOCK_BREAKPOINT=1024。
- 新增 `app/components/dashboard/DashboardRail.module.css`（railAnchor 撑满宽度 + railContent 让位 padding）。
  注意：**CSS 文件不能叫 `app/routes/app._index.module.css`**，会被 react-router 类型生成当成路由模块报 TS2344。
- `GenerationFlow.tsx`：新增内部 `SidePanel` 容器（docked 时不下发内联 left/width，交给 CSS），
  新增 `sidePanelDocked` prop；三个浮层统一使用它。
- `GenerationFlow.module.css`：新增 `.sidePanelDocked` 与 `@media (max-width:1023px)` 兜底。
- 关键避坑：让位 padding 必须施加在锚点元素的**内层**，否则测量自身会自激抖动；
  锚点外层需 `width:100%`，防止 s-page 用 flex/grid 居中时 rect.left 失真。
- 校验：`npx tsc --noEmit` 通过；`npx eslint` 仅剩改动前就存在的 a11y（div+onClick）与未使用变量告警。

## 微调 1：浮层左移 + 阴影收敛
- 常量拆分：`SIDE_PANEL_EDGE_INSET=12`（距视口左边缘，要再左移就调小）+ `SIDE_PANEL_GAP=24`。
- `.sidePanel` 阴影 `0 8px 32px` → `0 4px 16px`，避免大模糊晕染造成「压边」错觉；CSS 兜底 left 同步 0.75rem。

## 微调 2（最终方案）：取消让位，仪表盘内容左边缘永不位移
- 用户明确要求：**仪表盘内容左边缘保持原位不动**，否则左移浮层没有意义。
  已删除 `reserve` 机制与 `.railContent` 让位 padding（不再推挤仪表盘，也不会有布局跳动）。
- 新规则：浮层只在仪表盘左边缘以左的真实留白中活动，宽度按可用留白收敛：
  `panelWidth = min(320, 留白 - 12 - 24)`；`< 260` 或视口 `< 1024` → 退化底部通栏停靠。
- `useSidePanelRail` 返回 `{ anchorRef, panelWidth, docked }；
  `GenerationFlow` 新增 `sidePanelWidth` prop，由 `SidePanel` 下发内联 width。
- 激活瞬间（active 变 true）用 rAF 重测一次几何，防止布局变化导致数据过期（同时规避 effect 内同步 setState 的 lint）。
- `DashboardRail.module.css` 已重命名为 `DashboardAnchor.module.css`（只剩测量锚点 `.anchor { width:100% }`）。

## 微调 3：实测仍有重叠 → 改为「实测真实内容左边缘 + 闭环收窄」
- 现象：按 `min(320, 留白-36)` 取值后浮层仍然压到仪表盘，说明**锚点 rect.left 高估了留白**
  （疑似 s-page 的槽位用 min-content/居中轨道，内容溢出锚点框，真实左边缘更靠左）。
- 修正措施（不再依赖任何布局假设）：
  1. `readContentLeft()` = 锚点与其**直接子元素中最小的 left**（溢出场景取真实可见最左边缘）；
  2. 新增 `panelRef`，测量**浮层真实右边缘**，重叠则 `panelWidth -= overlap`（含 GAP=24）后重测，通常 1 次收敛；
  3. 兜底：`MAX_CORRECTIONS=6` 次校正无效 或 收窄到 `MIN_WIDTH=240` 以下 → `docked=true`（底部通栏，绝不重叠）。
  4. DEV 下 `console.debug("[sidePanelRail]", {contentLeft, panelRight, panelWidth, overlap})` 便于现场取证。
- `GenerationFlow` 新增 `sidePanelRef` prop，透传给 `SidePanel` / `ProgressModal` / `WritebackProgressView`。
- **排查下一步**：若仍重叠，让用户打开控制台贴 `[sidePanelRail]` 的 contentLeft / panelRight 数值即可定位。
